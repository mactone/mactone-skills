# Weekly Report Generator

此技能用於生成專業、結構化的週報，分析用戶在 Obsidian 知識庫中的活動。

## 核心流程

1. **資料搜集**：
    - 搜尋最近 7 天內修改過的 `.md` 檔案。
    - 重點檢查 `Daily notes/` 目錄下的最新日記。
    - 檢查 `Notes/` 中帶有 `建立時間: 2026-XX-XX` 的新內容。

2. **內容分析**：
    - **技術實作**：尋找關於軟體安裝、自動化 (openclaw, zeroclaw)、程式碼修復 (fix_links.py) 的內容。
    - **深度思考**：分析讀書筆記或共讀內容（如《預測之書》）。
    - **專業科研**：提取關於 HPC, OpenFOAM, 能源模擬, 氨燃燒專案的進展。
    - **個人成長**：理財知識、投資指標或思維提升。

3. **報告結構**：
    - **YAML Frontmatter**：包含標籤 `#週報`、建立時間與涵蓋範圍。
    - **正文區塊**：
        - 🤖 技術實作
        - 🧠 深度思考
        - 🧪 專業技術與科研
        - 📈 財富與個人成長
    - **核心總結與下一步建議**：包含關鍵詞與行動清單。

## 使用指南

- 確保輸出的標籤欄位包含 `#週報`。
- 檔案命名規範：`Week Reports/YYYY-W[週數]-週報.md`。
- 寫作風格：以友好的合作者角度（Antigravity），總結並提供洞察。
